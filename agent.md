# VendorBridge Frontend Direction

Follow this file strictly for all future frontend work in this repo.

## Strict Rules
- Do not make the UI look like vibe code.
- Do not add unnecessary boxes.
- Do not add decorative cards, decorative panels, or filler sections.
- Tables must look professional, clean, and business-ready.
- Forms, navigation, and page headers must stay simple and professional.

## Design Direction
- Build a clean professional ERP interface.
- Primary color is purple.
- Keep the layout structured, calm, and product-focused.
- Use spacing, typography, and alignment to create hierarchy instead of extra visual decoration.

## Layout Direction
- Every visible section must have a real product purpose.
- Avoid flashy dashboard patterns.
- Avoid artificial summary widgets unless they support a real workflow.
- Keep desktop and mobile layouts readable and consistent.
